# ExamForge

Generate exams from study material using AI, then let students take them and get auto-graded.

## Features
Upload a PDF or paste notes — AI generates questions with an answer key
Choose difficulty and number of MCQs, short, and long questions
Students join with a code, take the exam, and get an instant scorecard
MCQs graded instantly, written answers graded by AI with feedback

## Tech stack
Next.js + React + Tailwind CSS
Groq (Llama 3.3 70B) for generation and grading
Supabase for the database
unpdf for reading PDFs
